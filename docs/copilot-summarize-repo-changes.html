Change notes

Expandable notes for the important practical changes.

Agent workflow is now first-class
The branch adds a shared AGENTS.md, Claude-specific guidance, Claude skill symlinks, and a full .agents/skills tree. Skills cover diagnosis, TDD, triage, PRD/issue creation, prototyping, handoff, architecture review, and concise “caveman” mode.
Beads becomes the repo issue tracker
bd init adds .beads config, hooks, metadata, and exported issues. The repo now has a local Dolt-backed issue workflow with 10 open issues at branch time and agent rules to use bd rather than ad-hoc TODOs.
Catnap direction is documented, not implemented yet
The manifesto and vendor-neutral architecture propose a fork direction: keep Catnip’s local-first, git-backed workspace core, but make Claude, GitHub, Cloudflare, Apple runtime, hosted relay, and issue tracker integrations explicit adapters.
Pi becomes the next concrete adapter research path
The branch retargets near-term AgentRunner exploration to Pi, researches the VS Code extension landscape, adds pi0.pi-vscode to the devcontainer, and configures pi-vscode.path for the installed Pi binary.
Runtime cleanup narrows the active agent surface
Gemini CLI is no longer installed in the container image, transcript UI now says Claude-only, and legacy Gemini model docs are demoted. Separate fixes make catnip purr tolerate normal PTY closure and make local binary installs atomic.

Net effect

copilot/summarize-repo turns an already-working agent workspace manager into a repo that explains itself, tracks its own work, routes agents through named skills, and points toward a vendor-neutral Catnap core.
